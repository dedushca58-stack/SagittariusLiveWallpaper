# Sagittarius Live Wallpaper

Чистый проект живых обоев Android. Картинка не нужна: фон, стеклянная панель, синий медальон и золотой символ Стрельца рисуются приложением. Световой блик движется внутри медальона.

## Сборка
GitHub Actions автоматически собирает APK при каждом обновлении ветки main. Готовый файл находится в разделе Actions → последний успешный запуск → Artifacts.

## Установка
Установите APK на телефон, откройте приложение и нажмите «Установить живые обои». Затем подтвердите установку в системном окне Android.
